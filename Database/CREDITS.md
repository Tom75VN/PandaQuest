# Database Credits

PandaQuest bundles ONE merged world database: the complete **Vanilla** database
from **pfQuest** (Burning Crusade `*-tbc.lua` data excluded), with the
**Turtle WoW 1.18.1** records of **pfQuest-turtle 1.0.38** merged over it.

The Vanilla content originates from the VMaNGOS world database and is packaged by
pfQuest. The Turtle WoW content is packaged by pfQuest-turtle.

- VMaNGOS — world database source used by pfQuest
- pfQuest-turtle 1.0.38 — Rivi — MIT License (pfQuest's), https://github.com/rivi-s/pfQuest-turtle

## How the files are built

Every file in this folder except `init.lua`, `instances.lua`, `factions.lua`,
`dungeon_approach_units.lua`, `worldmap.lua` and this one is GENERATED by
`tools/import_turtle_db.py` from two read-only inputs in
`#Addons-dev/references/`:

- `PandaQuest_Vanilla_DB_0.5.2` — this folder as shipped in PandaQuest 0.5.2;
- `PandaQuest_Turtle_DB_Rivi_1.0.38_Ready` — the pfQuest-turtle overlay.

The merge follows pfQuest's own rules: a Turtle row replaces the Vanilla row and
`"_"` deletes it. Rivi's hand-maintained correction scripts
(`feature-compat-turtle.lua`, `overwrites-turtle.lua`) are executed unchanged
before the merge. Do not edit the generated files: re-run the importer. See
`docs/TURTLE-DB.md` for every rule and `tools/turtle_import_report.json` for the
last run's counts.

PandaQuest changes only the packaging: the Lua namespace (`PandaQuestData`), list
encoding, dropped empty item rows and exact duplicate spawn points, and the
bundled locales. The world records themselves are kept as packaged upstream,
except that VMaNGOS quest rewards (`xp`, `rep`) are carried onto a Turtle quest
whose level is unchanged.

Included locales: enUS, esES, frFR, ruRU, zhCN. pfQuest's deDE, koKR, ptBR and
zhTW tables are not shipped. A translated row is kept only while it still
translates the current English row; every name or text without one is read from
enUS, row by row. pfQuest-turtle ships no French text, so Turtle quests, NPCs,
objects, items and zones have no French row.

## VMaNGOS trainer and patrol additions

Trainer classification and permanent patrol data were extracted from
`db-sqlite-6958f26` (Vanilla 1.12.1). The Turtle WoW data has no patrol or
trainer tables of its own, so these remain Vanilla extracts, pruned of the
creatures Turtle deleted and of the patrols whose creature Turtle moved away
from its route. Turtle-only creatures have no patrol and no trainer record.

The optimized layout is locale-independent:
- `trainers.lua`: trainer metadata only; localized names and NPC positions are reused.
- `waypoint_index.lua`: lightweight NPC-to-route lookup.
- `Waypoints/*.lua`: deduplicated patrol routes split by world region.

`creature_movement_special` and `script_waypoint` are intentionally excluded because
they describe triggered/scripted/escort movement rather than normal permanent patrols.

## Instance-only creature provenance

`instance_only_units.lua` was extracted from VMaNGOS
`db-sqlite-6958f26` at the Vanilla 1.12.1 state. It records a creature only
when every active spawn's `creature.map` value is one of the dungeon or raid
maps shipped in `instances.lua`; creatures with outdoor or uncertain spawns
are excluded. The import removes a creature Turtle deleted or gave a spawn in a
Vanilla outdoor area. Turtle-only dungeons and their creatures are not covered.

`dungeon_approach_units.lua` is the complementary area-specific review layer.
Its creature IDs and representative coordinates come from the bundled
VMaNGOS/pfQuest data above; the classification was reviewed from PandaQuest's
Rare/Elite/Boss world-map pins in game on 2026-08-29. It covers entrance-cave
records that project onto an outdoor zone even though the source creature is
not globally instance-only.

## Vendor sell prices

`sellprices.lua` is the sell half of pfUI's `pfSellData` table (pfUI -- Eric
Mauser / Shagu -- MIT License), read from the local UnrealPfUI copy at
`env/tables.lua` by `tools/make_sell_prices.py`, then pruned of the items Turtle
WoW deleted. It is Vanilla 1.12 item data in copper: an item this server added
has no row, and an item it re-priced keeps the Vanilla value.

## Continent map rectangles

`worldmap.lua` is generated by `tools/import_worldmap_dbc.py` from the OctoWoW
client's own `DBFilesClient\WorldMapArea.dbc` and `WorldMapContinent.dbc`
(game data (c) Blizzard Entertainment, with the Turtle WoW client patches). It
holds only each zone map's rectangle on its continent map. The importer reads
the newest archive it can open; the encrypted Turtle patches (patch-1, -2, -4,
-5) cannot be read, so the last run used `patch-3.mpq`. Zones reworked after
that patch are filtered out at runtime by their yard size (see
`MapContext:GetContinentZoneTransform`).

## Patrol scope

Battleground and instance patrols are intentionally not shipped in the optimized
quest database. Only Eastern Kingdoms and Kalimdor permanent patrol routes are kept.
