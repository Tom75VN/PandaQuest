# ThinBorder texture attribution

These seven TGA files draw the quest-tracker NPC finder's eight-slice frame.
The missing bottom-right corner is made by mirroring the bottom-left texture.

They were copied byte-for-byte from pandaUI's
`media/Textures/modern-wow/ui/borders/` directory. Each file is a 32x32
Blizzard Modern WoW ThinBorder texture drawn at 16x16 interface units.

## Origin

Blizzard Entertainment UI art imported through pandaUI's Modern WoW theme.
See pandaUI's `media/Textures/modern-wow/ATTRIBUTION.md` for full provenance.
